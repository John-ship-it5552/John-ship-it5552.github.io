About me
======
Hello!

I am a junior undergraduate student at the College of Computer and Data Science, Fuzhou University, with a deep passion for computer science and a clear career goal of growing into a professional in the software industry.

My core learning focus is **full-stack software development**. I have built a solid technical foundation in Java backend engineering and modern frontend technologies, and I am committed to writing robust, scalable, and well-structured code. I enjoy the process of turning product requirements into complete, user-friendly applications, and I always pursue high code quality and standardized engineering practices in every project.

Beyond traditional software development, I have a strong interest in **large language models (LLMs) and artificial intelligence**. I am actively exploring how LLMs can empower software systems, including LLM-based application development, prompt engineering, and AI-aided programming workflows. I firmly believe that the deep integration of AI and software engineering will reshape the future of the tech industry, and I am continuously expanding my knowledge and hands-on experience in this field.

Currently, I am working to:

- Consolidate computer science fundamentals (data structures, algorithms, operating systems, etc.)
- Advance my full-stack development skills and dive into microservice architecture
- Explore practical, scenario-based applications of large language models
- Gain real-world project experience through hands-on development and open-source contribution

Learning plan
------
1. Consolidate CS Fundamentals

I will prioritize reinforcing core theoretical knowledge: data structures & algorithms, operating systems, computer networks, and database principles. I will practice 3–5 algorithm problems weekly on LeetCode to sharpen problem-solving skills, and systematically review course materials to build a robust theoretical base that supports all technical practice.

2. Advance Full-Stack Development

For backend, I will deepen my expertise in the Java ecosystem, especially Spring Cloud microservices, distributed development, and SQL optimization. For frontend, I will focus on Vue.js 3, frontend engineering (Vite, modular architecture), and responsive design. I will build at least one complete full-stack project per semester (e.g., a web management system), following strict code quality and version control standards.

3. Practice LLM Application Development

Following my interest in large language models, I will learn LLM API integration, prompt engineering, and common AI application patterns. I will develop small practical AI tools (such as intelligent code assistants or content processing utilities) by combining full-stack skills with LLM capabilities, gaining real-world experience in AI-empowered software.
